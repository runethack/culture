# culture

`culture` — это пентест-тул для автоматической разведки и первичной проверки IP-адресов и доменов. Он собирает данные из нескольких инструментов, проверяет типовые уязвимости и сохраняет результаты в отдельную папку для каждой цели.

> ⚠Важно: сканирование агрессивное. `culture` запускает много параллельных запросов, проверок портов, перебора путей, API-эндпоинтов и базовых веб-сканов. Это может создавать заметную нагрузку, активировать WAF/IPS/IDS и приводить к временной блокировке IP. Используйте инструмент только на системах, которыми вы владеете, или на тех, для которых у вас есть явное разрешение на тестирование. Не запускайте его против чужих ресурсов без согласования.

## Что делает

В базовом сценарии `culture`:

1. Принимает домен, IP или файл со списком целей.
2. Определяет IP-адрес для домена и подбирает User-Agent, который может дать лучший ответ от сайта.
3. Параллельно запускает набор проверок:
   - HTTP/HTTPS заголовки и базовый статус страницы;
   - проверку портов и сервисов через `nmap`;
   - WHOIS и DNS-записи;
   - поиск поддоменов;
   - определение технологий сайта и возможной WAF;
   - сбор публичных email-адресов и связанных данных;
   - проверку на уязвимости через `nuclei`;
   - проверку `sqlmap`, `nikto` и других инструментов;
   - перебор типовых путей и API;
   - проверку `robots.txt`, `sitemap.xml`, OAuth/OpenID и базовых защищённых маршрутов;
   - анализ потенциально опасных путей вроде `.git`, `.env`, `/admin`, `/wp-admin`, `/phpmyadmin` и т.д.
4. Сохраняет вывод каждого модуля и общий отчёт в папку вида:
   `culture_<цель>_<дата_время>`

Также можно сохранять JSON-отчёт через флаг `--json`.

## Как он работает

`culture` запускает набор готовых инструментов и склеивает их вывод в один отчёт.

Типичный цикл работы:

- цель задаётся вручную (`domain`, `ip` или список из файла);
- сканер пытается определить хост, IP и параметры ответа;
- запускаются параллельные задачи на проверку HTTP, DNS, доменов, WAF, путей и API;
- каждое обнаружение записывается в текстовый файл;
- в конце формируется сводка `SUMMARY.txt` (и `SUMMARY.json`, если включён режим JSON).

Важно: найденный путь, код ответа или открытый endpoint не всегда означает реальную уязвимость. Это скорее знак для дальнейшей ручной проверки, а не доказательство эксплойта.
